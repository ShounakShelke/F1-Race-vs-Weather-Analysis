# Jupyter Notebooks for F1 Weather Analysis

## 📓 Available Notebooks

This directory contains Jupyter notebooks for detailed analysis of the F1 weather data.

## 🚀 Getting Started

### Prerequisites
1. **Install Jupyter**: `pip install jupyter`
2. **Run data collection**: Execute the Python scripts first
3. **Data available**: Ensure data files exist in `../data/raw/`

### Starting Jupyter
```bash
# Navigate to project directory
cd F1-Race-vs-Weather-Analysis

# Start Jupyter server
jupyter notebook
```

## 📊 Notebook Workflow

### 1. Data Exploration
- Load collected F1 and weather data
- Examine data structure and quality
- Identify cleaning requirements

### 2. Data Cleaning
- Handle missing values
- Standardize formats
- Validate data integrity

### 3. Data Merging
- Combine race and weather data
- Create analysis-ready datasets
- Export for QGIS visualization

### 4. Statistical Analysis
- Perform hypothesis testing
- Calculate effect sizes
- Generate insights and recommendations
